# Přehled změn

Všechny významné změny projektu Extra Renta budou zaznamenávány v tomto souboru.

Formát vychází z principů Keep a Changelog a projekt používá sémantické verzování.

## [0.1.0] – 2026-07-24

### Přidáno

- první verzovaná podoba projektu v GitHub repozitáři,
- Streamlit webová aplikace se světlým industriálním vzhledem,
- generování, filtrování, scoring a MMR diverzifikace kandidátních kombinací,
- mechanické sedmiválcové počítadlo,
- historie běhů, porovnání kombinací a exporty CSV, JSON, HTML a ZIP,
- sada automatických testů a dokumentace projektu.

### Poznámka

Projekt negeneruje „výherní čísla“ a netvrdí, že historická data zvyšují matematickou pravděpodobnost výhry. Historická data slouží pouze pro analytiku, filtrování, scoring, porovnání a reporting.
